# Pico

Repository containing all of the pico game files for the Pico-8 fantasy programmable game console.

## Meta Pong — `pong.p8`

A Pong clone that adds a narrative AI. The player boots into what looks like a faithful
1972 arcade Pong replica and finds the second paddle unmanned; after two points the machine
introduces itself. Across five acts COM works through the five stages of grief, and the
gameplay rules change with him.
